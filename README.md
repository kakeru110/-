# 婚活市場価値診断（エンタメ版）

自分の「婚活市場価値スコア」を診断し、相手に求める条件と釣り合っているかをチェックする簡易 Web ツールです。

- **STEP 1**: 年齢・身長・年収・職業・外見・性格を入力すると、市場価値スコア（0〜100点、SS〜Eランク）を算出します。
- **自動提案**: 算出したスコアに見合う、一般的な相手条件の目安（年収・年齢・身長など）を自動で提示します。
- **STEP 2**: 相手に求める条件（例: 年収5000万円以上など）を入力すると、その条件のスコアを算出し、自分のスコアとの釣り合いを判定します。

## 使い方

`index.html` をブラウザで開くだけで動作します（ビルド不要）。

```
python3 -m http.server 8000
# http://localhost:8000/ にアクセス
```

## 注意事項

このツールはネット上でよく言われる「婚活市場での傾向」を元にした簡易的な計算式によるエンタメコンテンツです。統計的・科学的根拠はなく、人の価値や相性を測るものではありません。話のネタとしてお楽しみください。

## ファイル構成

- `index.html` — ページ本体・フォーム
- `style.css` — スタイル
- `app.js` — スコア計算ロジックと画面制御
